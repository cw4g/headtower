## Unreleased

- **Foundation.** Design system in place - the schematic operator-console look:
  graphite ink neutrals, beacon-amber accent, functional status colors, and the
  hairline grid backdrop.
- **Machines.** The core node readout, with online state, addresses, tags, and
  key expiry shown in mono and tabular figures.
- **Dashboard.** The signature tailnet coverage view - the control tower at
  center, nodes on range rings, signal strength standing in for connectivity.
- **Access & ACLs, Routes, Settings, Command palette.** In active development;
  see [Features](/features) for the current shape of each view.
